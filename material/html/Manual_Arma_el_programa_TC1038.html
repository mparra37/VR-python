Arma el programa

El Operador les dice el número de programa y les lee las líneas de código que ve (con sangría o sin sangría). Ustedes deciden en qué número de línea va cada una, siguiendo el pseudocódigo. Cuidado: hay líneas trampa que se parecen pero no van. Sangría = 4 espacios.

Programa 1 · Suma de 1 a n

Pide n y muestra la suma 1 + 2 + … + n usando un ciclo for.

PSEUDOCÓDIGO (en este orden)
  1. Pide n (entero).
  2. Empieza la suma en 0.
  3. Para cada i de 1 a n (incluido n):
  4. suma i a la suma.
  5. Muestra la suma (fuera del ciclo).
EJEMPLO DE EJECUCIÓN
n: 5
Suma: 15

Programa 2 · Cuenta regresiva

Pide un número y cuenta hacia atrás hasta 1 con un ciclo while. Al final muestra ¡Despegue!

PSEUDOCÓDIGO (en este orden)
  1. Pide el número n (entero).
  2. Mientras n sea mayor que 0:
  3. muestra n.
  4. réstale 1 a n.
  5. Muestra ¡Despegue!
EJEMPLO DE EJECUCIÓN
Desde: 3
3
2
1
¡Despegue!

Programa 3 · Promedio del grupo

Calcula el promedio de una lista de promedios sin usar sum().

PSEUDOCÓDIGO (en este orden)
  1. Crea la lista prom con 92.5, 64.5 y 84.0.
  2. Empieza el total en 0.
  3. Para cada p en prom:
  4. súmale p al total.
  5. Muestra total entre el tamaño de la lista, con 2 decimales.
EJEMPLO DE EJECUCIÓN
80.33

Programa 4 · Buscar alumno

La función buscar(nombres, x) regresa la posición de x en la lista, o -1 si no está.

PSEUDOCÓDIGO (en este orden)
  1. Define la función buscar con nombres y x:
  2. para cada posición i de la lista:
  3. si el nombre en i es x:
  4. regresa i.
  5. después del ciclo, regresa -1.
  6. Muestra buscar de la lista Ana, Javier, Omar con Omar.
EJEMPLO DE EJECUCIÓN
2

Programa 5 · Lista de aprobados

Con dos listas paralelas, arma una lista nueva con los nombres de quienes tienen 70 o más.

PSEUDOCÓDIGO (en este orden)
  1. Crea la lista nombres: Ana, Javier, Omar.
  2. Crea la lista prom: 92.5, 64.5, 84.0.
  3. Empieza aprobados como lista vacía.
  4. Para cada posición i:
  5. si el promedio en i es 70 o más:
  6. agrega el NOMBRE en i a aprobados.
  7. Muestra aprobados y cuántos son.
EJEMPLO DE EJECUCIÓN
['Ana', 'Omar'] 2

Programa 6 · Mejor promedio

Encuentra al alumno con el promedio más alto sin usar max(). Si hay empate, gana el primero.

PSEUDOCÓDIGO (en este orden)
  1. Crea la lista nombres: Ana, Javier, Omar.
  2. Crea la lista prom: 92.5, 64.5, 84.0.
  3. El mejor empieza en la posición 0.
  4. Para cada posición i desde la 1:
  5. si el promedio en i es MAYOR que el del mejor:
  6. el mejor ahora es i.
  7. Muestra el nombre y el promedio del mejor.
EJEMPLO DE EJECUCIÓN
Ana con 92.5

Programa 7 · Eliminar alumno

Quita a Javier de las dos listas paralelas para que sigan alineadas.

PSEUDOCÓDIGO (en este orden)
  1. Crea la lista nombres: Ana, Javier, Omar.
  2. Crea la lista prom: 92.5, 64.5, 84.0.
  3. Busca la posición de Javier en nombres.
  4. Quita esa posición de nombres.
  5. Quita la MISMA posición de prom.
  6. Muestra las dos listas.
EJEMPLO DE EJECUCIÓN
['Ana', 'Omar'] [92.5, 84.0]

Programa 8 · Lugar en el grupo

El lugar de cada alumno es 1 más cuántos tienen un promedio mayor. Sin ordenar las listas (ciclo anidado).

PSEUDOCÓDIGO (en este orden)
  1. Crea la lista nombres: Ana, Javier, Omar.
  2. Crea la lista prom: 92.5, 64.5, 84.0.
  3. Para cada alumno i:
  4. su lugar empieza en 1.
  5. para cada alumno j:
  6. si el promedio de j es mayor que el de i:
  7. súmale 1 al lugar.
  8. muestra el nombre de i y su lugar.
EJEMPLO DE EJECUCIÓN
Ana - lugar 1
Javier - lugar 3
Omar - lugar 2
