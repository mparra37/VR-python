Intérprete humano

El Operador les lee una instrucción como print(f3(600)). Busquen la función, síganla a mano con esos valores y díganle exactamente qué imprime Python (540.0 no es lo mismo que 540). El Operador dispara a esa respuesta.
Orden de las operaciones (primero → último)Recuerden
( ) → ** → * / // % → + -/ siempre da decimal (10 / 5 = 2.0) · // divide sin decimales · % es el residuo · una función sin return regresa None

Función 1 · // y %

def f1(a, b):
    return a // b + a % b

Función 2 · precedencia

def f2(x):
    return 2 + x * 3 ** 2 // 4

Función 3 · if y operaciones

def f3(total):
    if total >= 500:
        total = total * 0.9
    return total

Función 4 · print contra return

def f4(x):
    print(x * 2)

Función 5 · if, elif, else

def f5(x):
    if x > 10:
        return "A"
    elif x > 5:
        return "B"
    else:
        return "C"

Función 6 · or y and

def f6(edad, permiso):
    if edad >= 18 or permiso:
        return "Pasa"
    return "No pasa"

Función 7 · math.ceil

def f7(alumnos):
    return math.ceil(alumnos / 4)

Función 8 · una función que llama a otra

def doble(x):
    return x * 2

def f8(x):
    return doble(x) + 1

Función 9 · promedio y round

def f9(c1, c2, c3):
    return round((c1 + c2 + c3) / 3, 1)

Función 10 · return dentro de if

def f10(horas):
    if horas <= 1:
        return 20
    return 20 + (horas - 1) * 15

Todas las funciones tienen import math al inicio del programa.
