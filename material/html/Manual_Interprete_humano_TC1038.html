El Operador les lee una instrucción como print(f3(600)). Busquen la función, síganla a mano con esos valores y díganle exactamente qué imprime Python (540.0 no es lo mismo que 540). El Operador dispara a esa respuesta.
Recuerden
range(1, n) llega hasta n − 1 · lista[-1] es el último · return dentro de un ciclo termina la función · pop(i) quita la posición i y recorre las demás

Función 1 · range y acumulador

def f1(n):
    total = 0
    for i in range(1, n):
        total += i
    return total

Función 2 · while

def f2(n):
    while n < 20:
        n = n * 3
    return n

Función 3 · índices y nums[-1]

def f3(nums):
    return nums[1] + nums[-1]

Función 4 · contar con if

def f4(prom):
    cuenta = 0
    for p in prom:
        if p >= 70:
            cuenta += 1
    return cuenta

Función 5 · buscar

def f5(nombres, x):
    for i in range(len(nombres)):
        if nombres[i] == x:
            return i
    return -1

Función 6 · el mayor sin max()

def f6(prom):
    mejor = 0
    for i in range(len(prom)):

    return mejor

Función 7 · ciclo anidado

def f7(a, b):
    cuenta = 0
    for i in range(a):
        for j in range(b):
            cuenta += 1
    return cuenta

Función 8 · lugar en el grupo

def f8(prom, i):
    lugar = 1
    for p in prom:
        if p > prom[i]:
            lugar += 1
    return lugar

Función 9 · listas paralelas

def f9(nombres, prom, x):
    pos = nombres.index(x)
    nombres.pop(pos)
    prom.pop(pos)
    return prom
