La máquina de funciones

El Operador les dicta un programa corto, por ejemplo a = area(3, 4) y print("Área:", a). Busquen la función aquí y díganle, en orden: 1) qué valor recibe cada parámetro, 2) qué regresa la función y 3) qué aparece en la pantalla.
Recuerden
Los valores entran a los parámetros en orden: el primero al primero. El nombre de la variable no importa: en resta(b, a) el parámetro a recibe el valor de b.
Antes de llamar, Python calcula lo que está entre paréntesis: es_par(n + 1) con n = 7 manda un 8.
return regresa un valor a quien llamó. print solo lo muestra en la pantalla. Si la función no tiene return, regresa None.
Lo que regresa se dice como valor de Python: los textos van entre comillas ('Aprobado'), los decimales con punto (9.0).

Máquina 1 · doble

def doble(x):
    return x * 2

Máquina 2 · cuadrado

def cuadrado(x):
    return x ** 2

Máquina 3 · area

def area(base, altura):
    return base * altura

Máquina 4 · resta

def resta(a, b):
    return a - b

Máquina 5 · promedio

def promedio(a, b, c):
    return (a + b + c) / 3

Máquina 6 · es_par

def es_par(n):
    return n % 2 == 0

Máquina 7 · aprobado

def aprobado(cal):
    if cal >= 70:
        return "Aprobado"
    return "Reprobado"

Máquina 8 · mayor

def mayor(a, b):
    if a > b:
        return a
    else:
        return b

Máquina 9 · descuento

def descuento(precio, porcentaje):
    return precio - precio * porcentaje / 100

Máquina 10 · saluda

def saluda(nombre):
    print("Hola", nombre)

Máquina 11 · imprime_area

def imprime_area(base, altura):
    print("Área:", base * altura)

Máquina 12 · muestra_doble

def muestra_doble(x):
    print(x * 2)
    return x * 2

Máquina 13 · envio

def envio(precio):
    if precio >= 500:
        return 0
    return 50

Máquina 14 · total

def total(precio):
    return precio + envio(precio)
