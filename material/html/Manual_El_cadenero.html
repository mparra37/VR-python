El cadenero

El Operador les dice el número de función y los valores, por ejemplo entra(18, 1.60): parámetro 1 = 18, parámetro 2 = 1.60. Pongan cada valor en su parámetro (edad = 18, estatura = 1.60), resuelvan cada comparación y díganle qué regresa la función. El Operador elige esa respuesta.
OperadorDa True cuando…Ejemplo
andlas dos partes son TrueTrue and False → False
oral menos una parte es TrueTrue or False → True
notlo de adelante es False (lo voltea)not True → False
Ordenprimero las comparaciones (> < >= <= == !=), luego not, luego and y al final or. Lo que está entre ( ) va primero.
TrucoEscriban True o False arriba de cada comparación; luego júntenlas con and / or.

Función 1 · entra

def entra(edad, estatura):
    if edad >= 18 and estatura > 1.50:
        return True
    else:
        return False

Función 2 · descuento

def descuento(edad):
    return edad < 12 or edad >= 60

Función 3 · en_rango

def en_rango(x):
    return x >= 1 and x <= 10

Función 4 · es_finde

def es_finde(dia):
    return dia == "sábado" or dia == "domingo"

Función 5 · puede_jugar

def puede_jugar(tarea, castigado):
    return tarea and not castigado

Función 6 · abierto

def abierto(hora, festivo):
    return hora >= 9 and hora < 18 and not festivo

Función 7 · aprueba

def aprueba(cal, faltas):
    return cal >= 70 and not faltas > 3

Función 8 · par_positivo

def par_positivo(n):
    return n % 2 == 0 and n > 0

Función 9 · boleto

def boleto(edad, estudiante):
    if edad < 12 or estudiante:
        return "Medio"
    elif edad >= 60:
        return "Gratis"
    else:
        return "Completo"

Función 10 · clima

def clima(temp, lluvia):
    if lluvia and temp < 15:
        return "Quédate"
    elif lluvia or temp < 15:
        return "Chamarra"
    else:
        return "Sal"

Función 11 · acceso

def acceso(edad, invitado, vip):
    return (edad >= 18 and invitado) or vip

Función 12 · beca

def beca(prom, ingreso):
    return prom >= 90 or (prom >= 80 and ingreso < 5000)
