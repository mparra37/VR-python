Arma el programa

El Operador les dice el número de programa y les lee las líneas de código que ve (con sangría o sin sangría). Ustedes deciden en qué número de línea va cada una, siguiendo el pseudocódigo. Cuidado: hay líneas trampa que se parecen pero no van. Sangría = 4 espacios.

Programa 1 · Área de un rectángulo

Pide la base y la altura de un rectángulo y muestra su área.

PSEUDOCÓDIGO (en este orden)
  1. Pide la base (decimal).
  2. Pide la altura (decimal).
  3. Calcula el área: base por altura.
  4. Muestra el área.
EJEMPLO DE EJECUCIÓN
Base: 4
Altura: 2.5
Área: 10.0

Programa 2 · Minutos a horas

Pide un total de minutos y lo muestra en horas y minutos.

PSEUDOCÓDIGO (en este orden)
  1. Pide el total de minutos (entero).
  2. Las horas son el total dividido entre 60, sin decimales.
  3. Los minutos que sobran son el residuo entre 60.
  4. Muestra horas y minutos.
EJEMPLO DE EJECUCIÓN
Minutos: 135
2 h 15 min

Programa 3 · Mesas para el salón

En cada mesa caben 4 alumnos. Pide cuántos alumnos hay y muestra cuántas mesas se necesitan.

PSEUDOCÓDIGO (en este orden)
  1. Usa la biblioteca de matemáticas.
  2. Pide el número de alumnos (entero).
  3. Mesas: alumnos entre 4, redondeado hacia ARRIBA.
  4. Muestra las mesas.
EJEMPLO DE EJECUCIÓN
Alumnos: 25
Mesas: 7

Programa 4 · Descuento en la tienda

Si la compra es de $500 o más, tiene 10% de descuento. Muestra el total a pagar.

PSEUDOCÓDIGO (en este orden)
  1. Pide el total de la compra (decimal).
  2. Si el total es 500 o más:
  3. el total ahora es el 90% del total.
  4. Muestra el total a pagar (fuera del si).
EJEMPLO DE EJECUCIÓN
Total de la compra: 600
Total a pagar: 540.0

Programa 5 · Par o impar

Pide un número entero y dice si es par o impar.

PSEUDOCÓDIGO (en este orden)
  1. Pide un número entero n.
  2. Si el residuo de n entre 2 es 0:
  3. muestra Par.
  4. Si no:
  5. muestra Impar.
EJEMPLO DE EJECUCIÓN
Número: 7
Impar

Programa 6 · Promedio y aprobado

La función promedio(c1, c2, c3) regresa el promedio de tres calificaciones. Se aprueba con 70 o más.

PSEUDOCÓDIGO (en este orden)
  1. Define la función promedio con c1, c2 y c3:
  2. regresa la suma de las tres entre 3.
  3. Guarda en p el promedio de 80, 90 y 70.
  4. Muestra el promedio.
  5. Si p es 70 o más:
  6. muestra Aprobado.
  7. Si no:
  8. muestra Reprobado.
EJEMPLO DE EJECUCIÓN
Promedio: 80.0
Aprobado

Programa 7 · Compra válida

Pide el total. Si es negativo, avisa del error. Si es 500 o más, cobra con 10% de descuento. Si no, cobra completo.

PSEUDOCÓDIGO (en este orden)
  1. Pide el total (decimal).
  2. Si el total es menor que 0:
  3. muestra el error.
  4. Si no, pero si es 500 o más:
  5. muestra el total con 10% de descuento.
  6. Si no:
  7. muestra el total completo.
EJEMPLO DE EJECUCIÓN
Total: 300
Pagas: 300.0

Programa 8 · Estacionamiento

La primera hora cuesta $20 y cada hora extra $15. La función tarifa(horas) regresa cuánto se paga.

PSEUDOCÓDIGO (en este orden)
  1. Define la función tarifa con horas:
  2. si las horas son 1 o menos:
  3. regresa 20.
  4. regresa 20 más 15 por cada hora extra.
  5. Pide las horas (entero).
  6. Muestra lo que se paga.
EJEMPLO DE EJECUCIÓN
Horas: 3
Pagas: 50
