El archivero

El Operador ve dos listas como cajas (por ejemplo nombres y edades) y les lee una llamada, por ejemplo f3(nombres). Busquen la función: lista1 es la lista que mandaron (aquí, nombres). Díganle qué caja regresa la función ("el último de nombres", "la posición 2 de edades") y él la toca.
RecuerdenEjemplo con lista = ["Ana", "Luis", "Eva", "Omar", "Zoe"]
La primera posición es la 0lista[0] → "Ana" · lista[2] → "Eva"
Los negativos cuentan desde el finallista[-1] → "Zoe" · lista[-2] → "Omar"
len es cuántos elementos haylen(lista) → 5 · lista[len(lista) - 1] → "Zoe"
index dice en qué posición estálista.index("Eva") → 2
Los valores entran en ordenen f10(edades, nombres): lista1 es edades y lista2 es nombres

Función 1

def f1(lista1):
    return lista1[0]

Función 2

def f2(lista1):
    return lista1[2]

Función 3

def f3(lista1):
    return lista1[-1]

Función 4

def f4(lista1):
    return lista1[-2]

Función 5

def f5(lista1):
    return lista1[len(lista1) - 1]

Función 6

def f6(lista1):
    return lista1[len(lista1) // 2]

Función 7

def f7(lista1, i):
    return lista1[i]

Función 8

def f8(lista1, i):
    return lista1[i - 1]

Función 9

def f9(lista1, i):
    return lista1[-i]

Función 10

def f10(lista1, lista2):
    return lista2[0]

Función 11

def f11(lista1, lista2, x):
    return lista2[lista1.index(x)]
